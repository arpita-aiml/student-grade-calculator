# Student Grade Calculator

A simple beginner-friendly Python program that calculates a student's total marks, average, and letter grade based on marks in 3 subjects.

## Features

- Takes student name and marks for 3 subjects as input
- Validates marks (must be between 0 and 100)
- Calculates total and average marks
- Assigns a letter grade (A, B, C, D, F) based on average
- Supports multiple students in one run (loop)
- Clean, well-commented code using functions

## Grading scale

| Average      | Grade |
|--------------|-------|
| 90 and above | A     |
| 75 - 89      | B     |
| 60 - 74      | C     |
| 40 - 59      | D     |
| Below 40     | F     |
